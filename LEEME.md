# entre palabras

Para cambiar de número, reemplaza en la carpeta `assets/` estos archivos con los mismos nombres:
`logo.png`, `cover.jpg` y `revista.pdf`.

Si el PDF tuviera otro nombre, cambia la línea `PDF_URL` al inicio de `leer.js`.
El sitio solo funciona desde un servidor (por ejemplo GitHub Pages), no abriendo el HTML con doble clic.
